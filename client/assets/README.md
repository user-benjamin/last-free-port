# Client assets

Drop art, audio, and fonts here. Godot auto-imports anything in the project
folder the moment the editor sees it (import metadata goes to `.godot/`,
which is gitignored; the small `.import` sidecar files that appear next to
assets SHOULD be committed — they store import settings).

## Formats

| You have | Use | How to show it |
|---|---|---|
| Still image | PNG, WebP, JPG, SVG | `TextureRect` (UI) or `Sprite2D` (world) |
| Animation / GIF | **GIFs don't work in Godot** — convert first | see below |
| Video | Ogg Theora (`.ogv`) | `VideoStreamPlayer` |
| Audio | WAV (sfx), Ogg Vorbis (music) | `AudioStreamPlayer` |

## The GIF caveat

Godot has no GIF support. To use an animated GIF:

1. Convert it to a **sprite sheet** (one PNG with every frame side by side —
   ezgif.com does this, or `ffmpeg`), then play it with an `AnimatedSprite2D`
   or an `AnimationPlayer` stepping a `TextureRect`'s region.
2. Or convert to `.ogv` video (`ffmpeg -i in.gif out.ogv`) and use a
   `VideoStreamPlayer` node.
